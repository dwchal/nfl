About the data & prediction model

The schedule and scores come from nflverse’s public game data. Saved data refreshes after one hour; use Refresh data for an immediate update. The app shows the latest available season and supports earlier seasons. Preseason games are excluded.

The backtested default evaluates the original Elo model and 27 margin-aware settings using only seasons before the selected year. Settings are selected on three older completed seasons, then the chosen candidate is compared with original Elo on three later completed seasons. It becomes the default only when both Brier error and log loss improve in that later comparison. That comparison is also the deployment gate; it is not a completely untouched final audit. Original Elo remains available in the model selector. The same settings apply to every team.

Each team starts at 1,500 Elo and ratings warm up using up to three preceding seasons. Margin-aware Elo weighs wins by logarithmic scoring margin, with a correction for strong favorites. Home advantage, update speed, and offseason carryover are tuned on the older seasons. Neutral games receive no home advantage. Original Elo uses a 20-point update factor, 55-point home advantage, and two-thirds carryover. Ties count as half a win for Elo, winning percentage, and probability-error evaluation; ties are excluded from pick accuracy.

Every backtest game is predicted before its score changes the ratings. Postseason games can update ratings, but the displayed test scores cover regular-season games. Current-season scores never tune the model’s settings. Brier error measures squared probability errors and log loss penalizes confident wrong predictions; lower values are better. Historical results do not guarantee future accuracy, and small team-specific samples can differ from league-wide results.

The outlook simulates all remaining regular-season games 10,000 times, updating ratings along each simulated path. Simulated rating changes use wins and losses alone because future score margins are unknown. The middle 80% range describes simulation outcomes, not a calibrated confidence interval. Future ties are not simulated. The forecast predicts regular-season wins; it does not predict playoff qualification.

The model does not account for injuries, roster changes, rest, weather, or betting markets. Historical season views use the final available season results for summaries and remaining-game estimates. Completed-game estimates replay ratings from before that game.
